## 🛡️ СИСТЕМА РАЗРЕШЕНИЙ ДЛЯ SHIELD - АРХИТЕКТУРА

### 🔧 **Как работает:**
1. **Filament Shield** автоматически регистрирует ресурсы RoleResource и PermissionResource
2. **Filament Shield генератор** создает разрешения для этих ресурсов
3. **Наши политики** (RolePolicy, PermissionPolicy) контролируют доступ
4. **Политики проверяют** `$user->hasRole('admin')`, а не конкретные разрешения

### ✅ **Преимущества:**
- Проще в поддержке
- Не нужно создавать кастомные разрешения
- Ясная логика: "админ видит все, остальные - нет"
- Политики не перезаписываются сидером (благодаря manualPolicies)

### 🔄 **Workflow разработки:**
1. Создаем политику: `sail artisan make:policy RolePolicy --model=Role`
2. Настраиваем политику (проверка на роль admin)
3. Добавляем в `manualPolicies` PermissionSeeder
4. Profit! 🎉
