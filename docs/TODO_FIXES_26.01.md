# 🔧 ИСПРАВЛЕНИЕ ОШИБКИ В ADDRESSESRELATIONMANAGER (26.01.2026)

## ПРОБЛЕМА:
**Ошибка**: `Unknown named parameter $where` в строке 42 `AddressesRelationManager.php`

**Причина**: В Filament 3.2 метод `->unique()` не поддерживает параметр `where` как именованный аргумент.

**Контекст**: Ошибка возникала при создании адреса в RelationManager проекта.

## РЕШЕНИЕ:

### 1. AddressesRelationManager.php
- Убрал использование `->unique()` с параметром `where`
- Заменил на массив правил с `Rule::unique()`
- Добавил условие `where('is_template', false)` через замыкание

### 2. AddressResource.php  
- Аналогично исправил правила валидации
- Добавил условие для раздельной проверки шаблонов и адресов

### 3. Address.php
- Добавил метод `rules()` для централизованной валидации
- Учел разделение по `is_template`
